# StreamdeckMobile (Android)

**StreamdeckMobile** is the Android companion app for the **StreamdeckMobilePC** desktop application. It connects via **WebSocket** to the desktop app, allowing users to remotely trigger sound effects that play on the PC and are streamed through tools like **OBS** or **Twitch Studio**.

> ⚠️ This app is intended to work exclusively with the `StreamdeckMobilePC` desktop application. It does not function as a standalone soundboard.

## 📱 Key Features

- 🔗 Connect to the desktop app by scanning a **QR code**
- 🎵 Load and display a list of available sounds
- 🖱️ Tap to trigger a sound, played on the desktop and heard on stream
- 🔄 Real-time communication using WebSockets
- ⚙️ Lightweight and responsive UI designed for fast access during live streams

## 🔌 How It Works

1. **Scan a QR Code** generated by the desktop app (`StreamdeckMobilePC` https://github.com/Microrax/StreamdeckMobilePC/tree/master)
2. The QR contains the **IP address** and **WebSocket port** of the PC
3. Establishes a **WebSocket connection** with the desktop
4. Loads the available sound list, sent from the PC
5. When a sound is tapped:
   - Sends the sound name via WebSocket to the desktop app
   - The desktop app forwards the name to the **Node.js server**
   - The sound is **played through the server**, and heard in the stream

## 🧱 Technologies Used

- **Java (Android SDK)**
- **WebSocket client**
- **QR Code scanning**
- **Multithreading** to handle background communication and UI updates

## 🛠️ Requirements

- Android
- Camera permission (to scan QR codes)
- Local network access (to connect to desktop app)

## 📷 Permissions

- `CAMERA` – Required to scan the QR code for connection
- `INTERNET` – Required for WebSocket communication

## 🔗 Pairing with Desktop App

To use this mobile app:

1. Launch the `StreamdeckMobilePC` desktop app
2. Click **"Generate QR Code"**
3. On your phone, open StreamdeckMobile and scan the QR
4. Wait for the connection to establish
5. Tap any sound to play it live on your stream!

## 🚧 Known Limitations

- Both devices must be on the same local network
- Desktop firewall or antivirus may block WebSocket traffic
- Extremely large sound lists may require slight UI optimization
